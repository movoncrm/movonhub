## 5. Content-change rules for implementation

1. **Never publish confidential fields** — no commission, incentive, unit-count,
   SBI or group-sales data on any public page or API response.
2. **Always show effective dates** and the "refer to MEMO / subject to change"
   advisory copied from the source.
3. Treat all figures as **promotional**; the normal price should still be shown
   where the source provides it (used to show savings).
4. Bilingual: every new public string needs **English and Bahasa Melayu** entries
   following the existing registry pattern (`src/i18n/en.ts`, `src/i18n/ms.ts`)
   and `site_content` overrides only for editable copy.
5. Any price or product addition is a **business decision** — confirm with
   MOVONHUB before publishing (see open questions in `DOCUMENT_STUDY.md`).
